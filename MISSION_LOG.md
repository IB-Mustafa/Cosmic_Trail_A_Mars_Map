# Mission log: team cosmiCore

## AI tools disclosure

We used AI coding assistants (Claude and Claude Code) to help us write code, tests, documentation and the data pipeline.
Every decision was ours: which datasets and layers to use, the libraries, the routing approach and how we sped it up, the slope rules, the UI, and keeping ARIA rule-based and offline.
ARIA's code was written with AI help, but ARIA itself is not a trained model and uses no AI when the app runs. Its answers come from our data and hand-written rules.
Before submitting, we reviewed every file ourselves and checked the sources and links in [DATA_SOURCES.md](DATA_SOURCES.md).
